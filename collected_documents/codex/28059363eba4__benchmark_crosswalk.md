# Benchmark and Standards Crosswalk

This crosswalk defines objective pre-Codex success criteria. A domain does not
receive a 10 because its prose sounds complete; it receives a 10 only when every
required artifact, evaluator, failure case, owner, rollback, and proof boundary
exists and passes.

## Agentic execution

OpenAI Harness Engineering, Symphony, and App Server provide the benchmark for
repository legibility, progressive disclosure, depth-first development,
issue-backed orchestration, isolated workspaces, persistent threads, and
agent-native feedback loops.

## AI and software risk

NIST AI RMF/AI 600-1, NIST SSDF, OWASP ASVS, and SLSA provide the benchmark for
risk ownership, secure development, application verification, artifact
provenance, incident response, and supply-chain integrity.

## Data, ML, and observability

JSON Schema, OpenAPI, AsyncAPI, CloudEvents, OpenTelemetry, OpenLineage, and
MLflow provide the benchmark for contracts, event semantics, lineage,
observability, versioning, model promotion, and rollback.

## Routing and experiments

OR-Tools VRPTW concepts define the routing constraint benchmark. CONSORT and its
cluster-randomized extension define the preregistration, allocation, cluster,
contamination, ITT, and reporting benchmark for the field experiment.
