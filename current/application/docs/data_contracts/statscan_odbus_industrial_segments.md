# ODBus Industrial Segmentation

## Core research pool

- Manufacturing: NAICS 31–33
- Wholesale trade: Canadian NAICS 41
- Transportation and warehousing: NAICS 48–49

## Adjacent research pool

- Detailed construction trades: NAICS 236, 237 or 238
- Selected facility services: NAICS 562, 56173, 56174, 56179
  or 56191

## Review-only evidence

- Broad two-digit construction code 23
- Broad two-digit support-services code 56
- Entities with evidence supporting multiple segments
- Identity-unresolved entities

Missing primary NAICS values are not automatically classified.

This historical segmentation is only a research baseline.
`outreach_eligible` is always false.
