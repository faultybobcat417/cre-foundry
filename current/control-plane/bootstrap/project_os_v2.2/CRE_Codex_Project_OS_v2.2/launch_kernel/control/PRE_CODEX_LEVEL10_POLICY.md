# Pre-Codex Level-10 Policy

“Level 10” has two separate axes.

## Axis A — design and evaluator readiness

A domain reaches 10/10 when it has complete authority, primitives, interfaces,
benchmarks, evaluators, negative cases, telemetry, rollback, ownership, and a
precise path for every unresolved input.

This axis can be proven before Codex builds the application.

## Axis B — evidence maturity

A domain advances only through the proof ladder. Simulations can prove software
behavior and analysis recovery under known synthetic truth. They cannot prove
real source coverage, real entity accuracy, real field lift, or commercial ROI.

## Release claim

The pre-Codex package may claim **10/10 design/evaluator readiness** only if every
domain passes the full campaign. It must still disclose the evidence maturity of
each empirical claim.
